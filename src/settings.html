Создать Google Api
В Google Api текст отправляется после паузы в наборе. Серое исправление можно принять нажатием. Offline не отправляет текст.
Win + буква или цифра; либо Ctrl + Alt + буква или цифра.
Win+0 — открыть по центру, Esc — скрыть в трей. Фоновый запуск включается вместе с горячей клавишей.
